# Security Policy

## Supported Versions

Currently, only the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| Forks   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within REIATSU (e.g., exposed API keys, XSS vulnerabilities in the UI, or unauthenticated proxy access), please **DO NOT** open a public issue.

Instead, please send a direct message or email to the repository owner to responsibly disclose the issue. 

We take security seriously and will work to release a patch as quickly as possible.
